コード記述練習アプリ

Python学習用アプリ

概要

Pythonのコードを入力し、実行結果と正解を比較して学習するアプリです。
初心者がコードに慣れることを目的とした練習用ツールです。

コンセプト

このアプリは、Python学習中に「理解できてもコードが書けない」という課題を解決するために開発しました。
書き方ではなく出力結果を基準に正誤判定することで、実践的なコーディング練習ができるように設計しています。

主な機能

  • コード入力フォーム
  • 自動実行・判定機能
  • 問題ランダム出題
  • スコア管理（session使用）

技術構成

  • Python
  • Flask
  • HTML / CSS

工夫した点

  • execの安全制御（import禁止）
  • print出力の取得処理
  • sessionで進捗管理

旧バージョン（Tkinter版）

Webアプリ開発の中間制作として作成したデスクトップ版です。
基本機能の実装とロジックの検証を目的に開発しました。
