コード記述練習アプリ

Python学習用アプリ

概要

Pythonのコードを入力し、実行結果と正解を比較して学習するアプリです。
初心者がコードに慣れるための練習用ツールです。

主な機能

  • コード入力フォーム
  • 自動実行・判定機能
  • 問題ランダム出題
  • スコア管理（session使用）

技術構成

  • Python
  • Flask
  • HTML / CSS

工夫した点

  • execの安全制御（import禁止）
  • print出力の取得処理
  • sessionで進捗管理
