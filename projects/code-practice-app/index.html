コード記述練習アプリ

Python / Flask 学習用アプリ

📌 概要

このアプリはPythonのコード入力と実行結果を使って、 プログラミングの基礎を練習できる学習用Webアプリです。

⚙️ 主な機能

  • コード入力フォーム
  • 自動実行・判定機能
  • 問題ランダム出題
  • スコア管理（session使用）

🧠 技術構成

  • Python
  • Flask
  • HTML / CSS

💡 工夫した点

  • execの安全制御（import制限）
  • print出力のキャプチャ処理
  • sessionでユーザー進捗管理

🚀 アプリを見る

※ローカル環境またはデプロイ環境で動作します
